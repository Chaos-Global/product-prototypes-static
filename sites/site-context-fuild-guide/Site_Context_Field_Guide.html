Key findings

Seven things the evidence shows

F1

Site context has split into massing and photoreal camps

Enscape (since 3.3, April 2022), Lumion, SketchUp and Forma import abstract OpenStreetMap geometry: low-poly buildings, streets and terrain. D5 Render streams Google 3D Tiles through Cesium, which gives photogrammetry buildings, trees and textures. The two serve different jobs: neutral massing for design review, believable surroundings for client and marketing images. Our analysis: no tool lets users move between the two on the same site.

AEC Magazine, Enscape 3.3; TRXL, D5 feature spotlight; D5 blog, geospatial data
F2

The import flow has converged

Lumion, SketchUp and Forma all follow the same steps. Locate by address, map or coordinates. Frame the extent with a circle, frame or pan. Filter the layers. Fetch the data. The import step is now table stakes.

Lumion, OpenStreetMap guide; SketchUp, Add Location; Autodesk Forma blog
F3

Real sites always clash with the proposal

The existing building or park sits where the design goes. D5 offers a void box (section cube) that cuts streamed context. Lumion lets users hide individual buildings. Forma users clean up by hand in Revit.

TRXL, D5 feature spotlight; Lumion, OpenStreetMap guide; BIM Pure, Forma to Revit
F4

Building heights are often guesses, and that isn't shown

Forma notes that most OSM buildings lack height data and assumes 3 m per level. Lumion falls back to default heights and offers a randomize option. Neither marks which buildings are estimated in the scene.

Autodesk Forma blog; Lumion, OpenStreetMap guide
F5

Photoreal tiles fail at street level and outside big cities

A D5 demo admits the limits of Google Earth data at street level and proposes AI style transfer as a fix. D5 forum users report that smaller cities and rural areas lack 3D coverage, and that terrain such as a coastline can be missing.

TRXL, D5 feature spotlight; D5 forum, OpenStreetMap integration
F6

Importing context into BIM brings cleanup and coordinate pain

From Forma to Revit, roads arrive as detail lines, water can arrive as grass, and the survey point often needs moving. Forma also needs the AEC Collection or a standalone subscription of about $185 a month.

BIM Pure, Forma to Revit; Autodesk Forma blog
F7

Users want it inside the renderer, in a few clicks

D5 forum users describe Dynamo and Blender detours as "tedious and time consuming" and point to Lumion and Twinmotion as models. Twinmotion's 2025.2 and 2026.1 release notes add no geolocation features; its landscapes are imported files placed at the origin.

D5 forum; Twinmotion release notes 2025.2 and 2026.1; Twinmotion, Importing landscapes
For UX designers
  • Design the steps after import first: making room, restyling and checking trust. The import itself is a solved, four-step pattern.
  • Treat "estimated" as a visible state of context geometry, not a silent default.
For product managers
  • D5 has photoreal context and Lumion has the deepest styling. Enscape's 2022-era OSM import is at parity on the import step only.
  • Google 3D Tiles bring coverage gaps, an online requirement and provider terms. Price these in before matching D5.

Competitive analysis

How seven products bring in site context

Each product's built-in site context path, rated against the patterns in this guide. Sources are vendor docs, release notes, press and forums, checked October 2026. Nothing was tested hands-on, so recheck a rating before quoting it. Enscape's current documentation could not be reached, and several of its cells are unverified.

Pattern support by product

Enscape

in-renderer OSM massing
Signature
A Site Context panel in the rendering window. Enter an address or coordinates, then import everything or only buildings and landmarks, streets and sidewalks, or topography, as low-poly geometry (AEC Magazine, 3.3). It works across Revit, SketchUp, Rhino, Archicad and Vectorworks.
Borrow
One context feature for every host, so the experience doesn't depend on the authoring tool.
Watch out
Our analysis: no public update to Site Context was found after 3.3. Clearing, styling and data-trust controls are not verified. Check them in the product.

Lumion

styled OSM layer
Signature
OpenStreetMap in the Landscape tab: pick a GPS point, set a radius circle and a direction arrow, and download a heightmap and satellite imagery. Then toggle layers, hide single buildings, apply a preset look, set a minimum height and transparency.
Borrow
Treating context as a layer with a look, so it can recede behind the design.
Watch out
Buildings without height data get default or randomized heights. Users can't see which ones those are.

D5 Render

streamed photoreal tiles
Signature
Since 2.10 (March 2025), D5 streams Google 3D Tiles through Cesium from an address search. A void box cuts conflicting context, a screen-space-error setting trades quality for speed, and weather and sun path follow the site.
Borrow
A volume that cuts context where the proposal goes, without editing the source data.
Watch out
It needs an internet connection, shows artifacts at street level and has thin rural coverage. "Maximum Screen Space Error" is engine jargon in the UI.

Twinmotion

file-based landscape
Signature
It imports a single landscape per project from a heightmap, point file or mesh, placed at the origin, then sculpts and paints it. Release 2026.1 moves the terrain to Unreal's landscape system, in preparation for "large open worlds".
Borrow
Strong terrain editing after import.
Watch out
There is no built-in location search or city import. Users assemble context in other tools, such as CityEngine.

SketchUp

geolocated model context
Signature
Add Location: search, align the red and green axes to True North, then set the geolocation. Import a flat or elevated site with a satellite or street map texture, choosing resolution, mesh density and 3D buildings. Each part lands on its own tag. PlaceMaker adds OSM roads, water and rail, plus Nearmap or Google 3D data.
Borrow
Aligning to North as an explicit step before import, so sun studies are right from the start.
Watch out
Site context needs at least a SketchUp Go subscription. Imported buildings are only simple geometry.

Revit + Forma

analysis-first site, sent to BIM
Signature
Order datasets in the Forma web app (OSM buildings and roads, EU-DEM or ASTER terrain, Mapbox imagery), place them in a proposal, and Send to Revit. They arrive as Toposolids and Generic Models on UTM coordinates.
Borrow
A coverage check before ordering, so users know what data exists for their address.
Watch out
It spans two apps and an add-in. Cleanup is manual, coordinates get overridden, and it costs about $185 a month outside the AEC Collection.

Archicad

partner and plugin context
Signature
No built-in city import was found. Graphisoft partnered with Cityweft in January 2026 to bring buildings and topography into a new design intelligence tool. Plugins such as ArchiTerra exist.
Borrow
Our analysis: partnering for data rather than building data pipelines in-house.
Watch out
Our analysis: Archicad users rely on Enscape's Site Context today, so any gap there becomes a gap in their workflow.
For UX designers
  • Lumion and D5 show two ends of a range: restyle the data, or replace it with reality. Pick a primary model and give the other a path.
  • SketchUp's North alignment and Forma's coverage check are small steps that prevent expensive mistakes later. Copy both.
For product managers
  • Parity baseline: address search, layer choice, terrain and imagery. The gaps to close are clearing, styling and photoreal.
  • Enscape is the only context tool here that runs inside five hosts. That reach is the moat to build on.

What stands out

Streaming removes modelling and keeps project files light, and the void box solves the clash with the proposal. The cost is control and reliability. The context is a single photogrammetry mesh: it needs a connection and degrades at street level. The quality control is labelled in engine terms rather than as an outcome the user chooses.

For UX designers
  • Each flow ends at a different moment of value: Enscape at import, Lumion at styling, D5 at cutting. Map Enscape's steps after import before designing any of them.
  • Label quality controls by outcome ("Draft" or "Final"), not by engine parameter.
For product managers
  • D5's void box is a small feature with large perceived value. It is a candidate for a fast follow.
  • Streaming changes the cost model: bandwidth, provider fees and offline failure become product issues.

Five trade-offs seen in real products

Massing or photoreal

Abstract massing is neutral and works everywhere, but looks unfinished in client images. Photoreal tiles persuade, but compete with the design and fail where coverage is thin.

Evidence: Enscape and Lumion import low-poly OSM; D5 streams Google 3D Tiles and adds AI enhancement for street level

Our recommendation: one geolocation with a fidelity switch, defaulting to massing in design views and offering photoreal for presentation views.

Stream or store

Streaming keeps files light and data fresh, but needs a connection and can change between sessions. Stored geometry works offline and is stable, but is heavy and goes stale.

Evidence: D5 streams and needs internet; SketchUp and Forma import geometry into the model

Stream while working, and offer "Freeze site" to cache the current extent for offline work and reproducible renders.

Import into the host or keep in the renderer

Host geometry can be used in drawings and coordinates, but brings cleanup and conflicts. A renderer-only layer stays clean, but documentation can't use it.

Evidence: Forma to Revit creates Toposolids and Generic Models that need fixing; Enscape keeps context in the renderer

Keep context in the renderer by default. Make export to the host an explicit action, with a coordinate preview first.

Automatic or truthful

Filling missing heights makes a complete skyline in one click, but presents guesses as facts in shadow and view studies.

Evidence: Forma assumes 3 m per level; Lumion randomizes missing heights

Fill gaps, but mark estimated buildings visually and let users type a known height for one building.

Engine control or user outcome

Exposing engine parameters gives experts control but asks everyone else to learn rendering internals.

Evidence: D5's "Maximum Screen Space Error" setting, 0 to 100

Show outcome presets (Draft, Balanced, Final) and keep the raw value in an advanced panel.

For UX designers
  • Every red cell needs a mitigation in the spec, such as a coordinate field as the accessible alternative to the map picker.
  • Silent estimation is the riskiest pattern in the set. Design its visible state before adding any new data source.
For product managers
  • Style presets and a void box are low to medium effort with high visible value. Streamed photoreal is high effort, plus provider terms.
  • Export to the host is the most expensive pattern. Fund it only if users ask for context in their drawings.

Summary

Do and avoid

Do

  • Read the location from the host's geolocation when it exists, instead of asking for an address again.
  • Show the extent on a map before fetching, with the size in metres.
  • Clear context under the project footprint by default, and let users restore any building.
  • Mark estimated building heights visibly and let users correct them.
  • Offer context style presets that match the view's visual style.

Avoid

  • Filling missing heights silently with defaults or random values.
  • Labelling quality settings with engine parameters such as screen space error.
  • Overriding the host's shared coordinates without a preview and a way back.
  • Making the map the only way to set a location.
  • Dropping context on a slow or lost connection without a cached fallback.
